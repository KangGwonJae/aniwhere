## 요약

프론트엔드를 전부 구현하지 않습니다. 기능지도의 우선순위대로 **실제로 동작하는 기능 6개, 프로토타입 2개, 슬라이드 6개**로 나누고, 화면은 3개만 만듭니다.

## POC와 프로토타입

| | POC (개념 증명) | 프로토타입 |
|---|---|---|
| 답하는 질문 | "이게 기술적으로 되나?" | "이게 어떤 모습이고 어떻게 쓰나?" |
| 생김새 | 투박해도 됨 | 그럴듯해야 함 |
| 데이터 | 진짜 데이터 | 가짜 데이터여도 됨 |

과제 평가 항목(VectorDB, 청킹, Workflow)은 POC 쪽에 있으므로, 핵심 기능은 진짜로 돌아가야 합니다.

## 화면 흐름

```
① 홈 ──(작품 클릭)──▶ ② 작품 상세 ◀──(작품 클릭)── ③ 내 기록장
  │                       │  ▲
  │ 05·06 질문/답변         │  │ 13 "몇 화까지 봤어요" 저장
  │                       ▼  │
  └──(답변 속 작품 링크)──▶ 09 맞춤 복습 (본 회차 = 기록장 값)
```

- 시청 기록(13)이 모든 기능을 잇습니다. 기록장의 진행 회차가 복습(09)과 스포일러 차단(11)의 범위가 됩니다.

## 와이어프레임

> 한글 폭 때문에 상자의 오른쪽 테두리는 생략했습니다. 작품 정보·OTT·회차·답변은 모양을 보여주기 위한 예시 값입니다. `[ ]`는 버튼, `( )`는 입력칸, `▸`는 링크입니다.

### ① 홈 — "그 애니 뭐였더라?" (05, 06)

```
┌─ AniWhere ─────────────────────────────────────
│ [홈]  [내 기록장]                     ⚙ 데모 작품: 귀멸·나히아·진격
├────────────────────────────────────────────────
│
│  그 애니 뭐였더라?
│  기억나는 장면이나 인물을 말해 주세요.
│
│  ( 키 작은 아저씨가 칼 들고 날아다니는 애니         ) [찾기]
│
│  ── 답변 ───────────────────────────────────────
│  🤖 진격의 거인 의 리바이 같아요.
│     ▸ 진격의 거인 작품 보기
│     근거 ▾  [캐릭터] Levi … (AniList)
│              [장면] 1기 22화 … (Fandom)
│
│  🤖 혹시 몇 화쯤인지도 찾을까요? 기억나는 장면을 더 알려 주세요.   ← 06
│     ( 거인 숲에서 여자 거인이랑 싸우던 장면          ) [보내기]
│
│  🤖 1기 21~22화 후보예요. 둘 중 어느 쪽인지 더 묻겠습니다:
│     [A. 숲에서 포위 작전]  [B. 리바이 반이 당하는 장면]
│
├────────────────────────────────────────────────
│  여유 되면:  [취향 인터뷰로 추천받기 (준비 중)]                  ← 01 프로토타입
└────────────────────────────────────────────────
```

- 후보가 비슷하면 버튼으로 추가 질문하고, 근거가 약하면 회차를 단정하지 않습니다(AGENTS.md 원칙 3).
- 답변마다 근거 청크를 펼쳐 볼 수 있게 합니다. 출처(AniList, Fandom 등)와 라이선스 표기도 여기서 해결됩니다.

### ② 작품 상세 (07, 13, 09)

```
┌─ AniWhere ─────────────────────────────────────
│ [홈]  [내 기록장]
├────────────────────────────────────────────────
│  [포스터]  나의 히어로 아카데미아
│            Boku no Hero Academia · 2016~ · 전체 170화
│            장르: 액션, 코미디 · ★ x.x (TMDB)
├─ 어디서 보나 (07) ─────────────────────────────
│  시즌 1   Netflix · Watcha · TVING · Crunchyroll
│  시즌 2   Netflix · Watcha · TVING
│  시즌 7   정보 없음
│  확인일 2026-10-05 · 출처 JustWatch via TMDB
├─ 내 시청 기록 (13) ────────────────────────────
│  몇 화까지 봤어요?  [시즌 3 ▾] [11화 ▾]  → 전체 49화   [저장]
│  평점 ☆☆☆☆☆
├─ 맞춤 복습 (09) ───────────────────────────────
│  📖 EP 1–49 기준 · 50화 이후 차단                               ← 11
│  무엇이 헷갈리세요?
│  [전체 요약]  [인물 관계]  [마지막 화 상황]
│  ( 직접 질문: 그 빨간 머리 애가 왜 편이 바뀌었지?        ) [묻기]
│
│  🤖 49화 시점까지의 줄거리예요. …
│     근거 ▾  3기 9화 · 3기 10화 · 3기 11화
├─ 탭 ───────────────────────────────────────────
│  [복습]  [인물 사전 (준비 중)]                                  ← 08 프로토타입
└────────────────────────────────────────────────
```

- 시청 기록이 없으면 복습 영역에 "어디까지 봤어요?"를 먼저 묻습니다. 기억이 안 나면 ① 홈의 회차 찾기(06)로 보냅니다.
- 회차 선택은 시즌·화로 받고, 내부에서는 `abs_ep`(전체 회차 번호)로 바꿉니다.
- 시청처 정보가 비어 있는 시즌이 데이터의 절반이므로 "정보 없음" 상태가 꼭 필요합니다.

### ③ 내 기록장 (13)

```
┌─ AniWhere ─────────────────────────────────────
│ [홈]  [내 기록장]
├────────────────────────────────────────────────
│  내 기록장 · 3작품
│
│  [포스터] 나의 히어로 아카데미아   49 / 170화  ███░░░░░  ★★★★☆   [이어서 복습 ▸]
│  [포스터] 진격의 거인              87 / 87화   ████████  ★★★★★   [다 봤어요]
│  [포스터] 귀멸의 칼날              12 / 63화   ██░░░░░░  ☆☆☆☆☆   [이어서 복습 ▸]
│
│  [+ 작품 추가]  ( 작품 이름 검색                       )
└────────────────────────────────────────────────
```

- `[이어서 복습 ▸]`은 ② 작품 상세의 맞춤 복습으로 바로 이동하고, 본 회차가 자동으로 채워집니다.
- POC 단계에서는 로그인 없이 한 사용자만 가정하고, 기록은 로컬 DB(SQLite)나 세션 저장소에 둡니다.

### 공통 — 스포일러 차단 배지 (11)

```
📖 EP 1–49 기준 · 50화 이후 차단
```

- 회차가 정해진 모든 답변 위에 붙입니다. 다른 LLM과의 차별점이므로 발표에서 강조합니다.
- 50화 이후 청크는 검색 결과에서 걸러내는 게 아니라, 검색 전에 제외합니다(AGENTS.md 원칙 2).

## 프론트와 백엔드 사이 약속 (안)

세 사람이 동시에 작업하려면 아래 형식을 먼저 확정해야 합니다. 프론트는 이 형식의 가짜 응답으로 먼저 만들 수 있습니다.

| 기능 | 요청 | 응답 |
|---|---|---|
| 05·06 찾기 | `question`, `history` | `answer`, `candidates[{series_id, abs_ep?}]`, `follow_up?`, `sources[]` |
| 07 시청처 | `series_id` | `seasons[{name, providers[], checked_at}]` |
| 09 복습 | `series_id`, `seen_ep`, `mode`(요약/인물/마지막 화/직접), `question?` | `answer`, `seen_ep`, `sources[{text, abs_ep, url, license}]` |
| 13 기록장 | `series_id`, `seen_ep`, `rating?` | 저장 결과 |

- `seen_ep`는 필수 인자입니다. 없으면 검색하지 않고 "어디까지 봤어요?"를 되묻습니다.

## 기술 선택 (결정 필요)

| 안 | 장점 | 단점 |
|---|---|---|
| Streamlit | 파이썬 하나로 백엔드와 바로 연결, 채팅 UI 기본 제공, 6일 안에 가능 | 디자인 자유도가 낮음 |
| HTML/JS + FastAPI | 보기 좋고 기능지도 디자인을 살리기 쉬움 | API 서버를 따로 만들어야 해서 일이 늘어남 |

- 추천은 Streamlit입니다. 단, 프론트 담당자가 웹에 익숙하면 HTML 쪽도 가능합니다.
