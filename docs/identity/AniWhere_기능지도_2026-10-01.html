09 맞춤 복습은 이렇게 움직인다

EP 01–11 본 회차 · 검색·요약에 사용| EP 12– 스포일러 차단
AGENT · 확인어디까지 봤나시청 기록장(13)에서 꺼냄. 없으면 "어디까지 봤어요?" → 기억으로 회차 찾기(06)
AGENT · 질문뭐가 헷갈리나전체 요약 / 인물 관계 / 마지막 화 상황
AGENT · 판단도구 고르기전체 요약 → DB 조건 검색
특정 궁금증 → Vector DB
AGENT · 답변본 회차까지만12화 이후 청크는 검색 전에 이미 제외
AGENT · 기억진행 저장다음 대화에서도 자동으로 스포일러 차단
Vector DB가 필요 없는 경우"1~11화 정리해줘" → 회차 조건으로 꺼내서 요약하면 끝WHERE episode <= 11
Vector DB가 제 역할을 하는 경우"그 빨간 머리 애가 왜 편이 바뀌었지?" → 11화 이하 청크 안에서 의미 검색filter(ep ≤ 11) → similarity search

청킹 포인트: 100화 넘는 작품은 전체를 한 번에 LLM에 넣기 어려우니, 회차 청크 위에 아크(이야기 묶음) 요약 청크를 하나 더 두는 계층형 청킹. 대표님이 강조한 "청킹 방식"으로 발표에 그대로 사용.

데이터 한계: 회차 줄거리는 Kitsu·TMDB는 짧고(죠죠 5부 20화 기준 4문장), 팬 위키는 자세함(같은 회차 약 1만 4천 자, CC BY-SA). 비인기작은 부실하므로 범위는 회차 설명이 충분한 작품으로 한정.
