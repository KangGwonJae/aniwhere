# 데이터 출처 비교 (작품 × 출처)

> 2026-10-05, 한태호. 수집기(`data/collect.py`)로 실제로 받아 본 결과입니다. 수치는 `data/processed/report.md`에서 다시 뽑을 수 있습니다.
> 이 표로 회차 지원 작품을 확정해 `config/settings.yaml`의 `works`에 반영합니다.

## 결론

**회차 뼈대와 한국어 줄거리는 TMDB, 영어 요약은 TVmaze, 장면 단위 상세 줄거리는 Fandom**으로 갑니다. Kitsu는 쓰지 않습니다.

- **TMDB가 기본 출처로 충분합니다.** 확인한 20개 작품 모두 한국어 회차 줄거리가 거의 전 회차에 있습니다(회차당 100~280자).
  당초 "한국어 줄거리는 비어 있는 회차가 많다"고 예상했지만, 인기 상위 300개 중 251개가 채움률 90% 이상이었습니다.
- **Fandom은 작품에 따라 갈립니다.** 인기 상위 300개 중 위키를 찾아 받은 작품이 166개이고, 그중 **81개가 채움률 90% 이상**입니다.
  강철의 연금술사처럼 문서는 있어도 내용이 얕은 작품이 있어서, 작품별 채움률로 회차 지원 여부를 정합니다.
- **데모 3작품(귀멸·나히아·진격)은 세 출처 모두 충분**합니다. 회차 번호도 출처 간에 정확히 맞물립니다(나히아 전체 49화 = TMDB 3기 11화 「원 포 올」 = TVmaze "One for All" = Fandom Episode 49).

수업 프로젝트(비상업) 용도라면 모두 출처 표기를 지키면 쓸 수 있습니다. 전체 표는 `data/README.md` 5절에 있습니다.

| 출처 | 라이선스 | 필수 조건 | 주의 |
|---|---|---|---|
| Fandom 위키 | 텍스트 CC BY-SA (받은 위키 모두 `CC-BY-SA` 표기, `fetch_log.detail`에 기록) | 출처 링크·라이선스 표기, 동일조건 공개 | 이미지·영상은 대상 아님. 가공 청크를 공개하면 같은 라이선스 |
| TVmaze API | CC BY-SA 4.0 | TVmaze 출처 링크, 동일조건 공개 | 10초에 20회 |
| TMDB API | 비상업 무료, 상업은 별도 계약 | TMDB 로고와 비보증 고지문 표시 | 데이터 장기 저장·AI 활용 조건은 약관 전문 확인 필요 |

| anime-offline-database | ODbL 1.0 + DbCL 1.0 | 출처 표기, 가공 DB 공개 시 동일조건 | |
| Fribb/anime-lists | **라이선스 파일 없음** | - | ID 연결용으로만 쓰고 재배포하지 않음 |

청크의 `sources` 칸에 출처 URL과 라이선스가 저장돼 있어 답변 근거 링크로 그대로 쓸 수 있습니다.

## 회차까지 지원할 작품 후보

1. **데모 (확정 권장):** 귀멸의 칼날, 나의 히어로 아카데미아, 진격의 거인
2. **바로 추가 가능 (직접 확인, Fandom 96% 이상):** 스파이 패밀리, 하이큐!!, 헌터×헌터(2011), 체인소 맨, 단다단, 데스노트, 봇치 더 록!, 나 혼자만 레벨업, 나루토 질풍전, 원피스
   - **자동으로 찾은 작품 중 90% 이상인 67개**도 후보입니다(위 "자동으로 찾은 Fandom 위키" 표). 켜기 전에 위키 주소가 맞는지만 확인하세요.
3. **시즌을 끊어서 지원:** 주술회전(2기까지), 장송의 프리렌(1기), 블루 록(1기)
4. **회차 찾기만:** 나루토, 강철의 연금술사 2종 — 그리고 한국어 줄거리가 있는 나머지 상위 작품 250여 개

작품을 늘리려면 `data/fandom_wikis.json`에 위키 주소를 한 줄 추가하고 `python data/collect.py fandom chunks report`를 실행한 뒤 리포트의 채움률을 확인합니다.

## 아직 없는 것

- **한국어 상세 줄거리:** Fandom 본문은 영어입니다. 다국어 임베딩으로 한국어 질문 ↔ 영어 본문을 검색하거나 번역해 넣어야 합니다.
- **세계관 용어(terminology) 청크, 아크 요약 청크:** 미수집. 아크 이름은 회차마다 저장돼 있어(`episodes.arc`) 아크 단위 요약을 만들 수 있습니다.
- **캐릭터 첫 등장 회차:** Fandom 등장인물 목록과 이름이 맞은 2,311명(전체 8,488명)만 회차 단위로 가립니다. 나머지는 시즌 단위입니다.
- **캐릭터 외형 묘사:** AniList 설명은 짧은 편입니다. "키 작은 아저씨가 커터칼 같은 칼" 같은 검색은 Fandom 캐릭터 문서(Appearance)를 추가로 받아야 잘 됩니다.
- **임베딩:** 코드(`embed`)만 준비했고 아직 실행하지 않았습니다.
