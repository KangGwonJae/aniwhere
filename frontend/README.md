# AniWhere Installable App Prototype V1

기존 웹 UI의 모든 화면과 기능을 포함하고, 설치 정보·앱 아이콘·오프라인 캐시를 추가한 설치형 PWA 앱 프로토타입입니다.

## 중요

- 실제 Vector DB, RAG, Agent, API, 영구 DB는 연결되어 있지 않습니다.
- 화면 전환과 대화는 합의 예정인 API 응답 형태를 가정한 가짜 데이터로 동작합니다.
- GitHub 업로드 전 팀 합의가 필요한 로컬 작업물입니다.

## 실행

`index.html`을 직접 열거나 아래처럼 실행합니다.

```bash
cd frontend
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 엽니다.

## 맥북에 설치

1. Chrome에서 `http://localhost:8000`을 엽니다.
2. 주소창 오른쪽의 설치 아이콘 또는 메뉴의 **AniWhere 설치**를 선택합니다.
3. 설치하면 독립 창과 Dock 아이콘으로 실행할 수 있습니다.

## 갤럭시에 설치

휴대폰 설치에는 HTTPS 주소가 필요합니다. 이 폴더를 HTTPS 호스팅한 뒤 Chrome에서 열고 **홈 화면에 추가** 또는 **앱 설치**를 선택합니다. 단순 LAN `http://192.168...` 주소로는 보안 정책상 설치·오프라인 기능이 제한될 수 있습니다.

Android APK는 향후 Capacitor를 적용하고 Java·Android Studio를 설치한 뒤 빌드합니다. 현재 컴퓨터에는 Java/Android 빌드 도구가 없어 APK는 아직 생성하지 않았습니다.

## 팀 리뷰 동선

1. **AI 대화**: 회차 찾기 대화를 진행하고, 상단 바로가기에서 `3분 복습` · `시청 순서` · `몇 화부터?` · `원작 연결`을 확인합니다.
2. **시청 기록**: 저장한 작품·회차, 기록 수정, 복습, 스포일러 범위, 새 시즌 알림을 확인합니다.
3. **탐색**: 상단 `빠른 가이드`에서 시청 순서·재미 시작점·원작 연결을, 아래에서 취향 인터뷰와 기타 확장 기능을 확인합니다.

`UI PROTOTYPE`으로 표시된 결과는 가짜 응답 데이터입니다. 팀 문서의 핵심 6개 기능도 현재는 프론트엔드 상태이며, 백엔드·Vector DB·실제 저장 연결이 남아 있습니다.

## 백엔드 연결 예정 형식

- 찾기: `question`, `history` → `answer`, `candidates`, `follow_up`, `sources`
- 시청처: `series_id` → `seasons[].providers`, `checked_at`
- 복습: `series_id`, `seen_ep`, `mode`, `question` → `answer`, `sources`
- 기록장: `series_id`, `seen_ep`, `rating` → 저장 결과
